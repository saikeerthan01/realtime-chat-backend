# Real-Time Chat Backend

A real-time chat backend built with Node.js, TypeScript, Express, PostgreSQL, JWT, bcrypt, and Socket.IO.

## Features

- User registration and login
- Password hashing with bcrypt
- JWT-protected REST APIs
- Create and list conversations
- Send and retrieve stored messages
- Secure Socket.IO authentication
- Conversation-specific Socket.IO rooms
- Real-time message delivery
- Real-time messages saved to PostgreSQL
- Permission checks so only conversation participants can join or send messages

## Tech Stack

- Node.js
- TypeScript
- Express
- PostgreSQL
- Socket.IO
- JSON Web Tokens
- bcrypt
